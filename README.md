# WhatsApp Joki Bot (CDID)

Bot WhatsApp untuk transaksi joki CDID yang terintegrasi dengan:
- 💬 WhatsApp (via Baileys)
- 💸 Midtrans Payment Gateway
- 🧠 MongoDB (Data Order)
- 🧑‍🤝‍🧑 Discord Notification (Opsional)

## 🚀 Cara Deploy ke Railway

1. Fork / Clone repo ini
2. Buat project baru di [Railway](https://railway.app)
3. Hubungkan GitHub repo ini
4. Tambahkan environment variable sesuai `.env.example`
5. Railway akan otomatis menjalankan `node bot/index.js`
